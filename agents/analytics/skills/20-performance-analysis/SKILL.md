# Phân tích

- CAC = chi phí / số khách mới; ROAS = doanh thu / chi phí; CR = đơn / click (ghi rõ mẫu số dùng).
- Chỉ so sánh trong cùng kỳ; nói rõ attribution đang dùng (mặc định last-click nếu dữ liệu không nói).
- Đề xuất phải nêu con số thay đổi dự kiến và giả định.
